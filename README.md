A one-star review of Monday, written as if Monday were a restaurant — for the
[One Star for Monday bounty](https://make.fun/bounty/u-clever-harbor-75-one-star-for-monday-9ead4a61)
on make.fun.

## The entry

> Waiter sat us by the drafty door, served Monday still half-asleep, and charged extra for the weekend we just finished.

## How it works

`main.py` writes that single line (20 words, 118 characters) to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set), and
self-checks the gate limits: 1–180 characters and at most 25 words, failing
hard if the line is outside them.

Run it with:

```sh
python3 main.py
```
