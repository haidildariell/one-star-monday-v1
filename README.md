## The entry

> Waiter sat us by the drafty door, served Monday still half-asleep, and charged extra for the weekend we just finished.

## How it works

`main.py` writes the single review line to `entry.txt` in the output
directory (`$MAKEFUN_OUTPUT_DIR`, default `/output`). Before writing, it
enforces the competition gate: one line, 1–200 characters, at most 25 words,
not whitespace-only. If the line ever broke the gate, the program would exit
non-zero without writing anything.

## Run

```sh
python3 main.py
```
